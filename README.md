# TBot — Telegram-бот для учёта расходов и задач

Бот для Александра и Сергея: партнёры пишут свободным текстом расходы и задачи,
бот через GLM извлекает данные, дозадает вопросы и пишет в Google Таблицу.

## Логика

1. Сообщение пользователя -> GLM: определить тип (расход / задача / ответ на вопрос / другое),
   извлечь поля (сумма, объект, исполнитель, срок, описание).
2. Для расхода обязательны: сумма, объект, описание. Для задачи: исполнитель, описание.
   Чего не хватает — бот спрашивает следующим сообщением, контекст диалога хранится в памяти.
3. Объекты и категории — динамические справочники (листы "Объекты", "Категории").
   Неизвестный объект -> вопрос с inline-кнопками: "Новый" + последние используемые объекты.
4. Категорию расхода LLM подбирает по описанию + примерам похожих прошлых расходов из таблицы.
5. Доступ только по белому списку Telegram ID (лист "Пользователи" + config.py).
6. Статусы задач: Новая -> В работе -> Сделана. Команда в чате: "задача 5 сделана".

## Структура

- `bot.py` — точка входа, вся логика диалогов
- `llm.py` — запросы к GLM (OpenAI-совместимый API)
- `sheets.py` — работа с Google Таблицей
- `config.py` — токены и настройки (создаётся из `config.example.py`)
- `requirements.txt`

## Запуск (локально для теста)

1. `pip install -r requirements.txt`
2. Заполнить `config.py` (токен бота, API-ключ GLM, путь к JSON сервисного аккаунта Google, ID таблицы)
3. `python bot.py`

## Google Таблица

Создаётся автоматически при первом запуске (`sheets.py: ensure_structure`):
листы Расходы, Задачи, Объекты, Категории, Пользователи, Сводка.
