# TBot2 — контекстный роутинг

Карта маршрутов «о чём задача → что читать» (§ 3.4 первоисточника СТРАТА).
Агент по постановке задачи находит здесь, какие файлы открыть. Подробное
поведение продукта — в `критерии_приёмки.md`, причины решений — в
`журнал_решений.md`, устройство и поставка — в `артефакты/tbot.json`.

## Маршруты

| Если задача про… | Читай | Что там найдёшь |
|---|---|---|
| учёт расходов | `bot.py::process_expense`, `sheets.py` | лист «Расходы» (Дата\|День\|Автор\|Описание\|Сумма\|Объект\|Категория), `guess_category`, сценарий С2 критериев |
| учёт задач | `bot.py::process_task`, `sheets.py` (`next_task_no`, `close_task`, `open_tasks`) | лист «Задачи», нормализация «Саня/Серёга», /tasks, /zaprosy, сценарий С3 |
| правка строк | `llm.pick_expense_row`, `bot.py` | поиск по сочетанию ВСЕХ признаков, кнопки выбора, сценарий С4 |
| LLM-классификация | `llm.py::extract` | action: expense/task/task_done/search/none; учёт в приоритете («купил доски» ≠ «найди где купить доски») |
| голосовые | `llm.py::transcribe` (glm-asr-2512), `bot.py` | расшифровка + кнопки «Да/Нет»; грабля: у `Voice` НЕТ `file_name` → getattr (инвариант в паспорте) |
| доступ/безопасность | `bot.py` (`check_access`, `on_access_decision`), `config.py` | белый список = env USERS ∪ листы «Пользователи» обеих таблиц ∪ config_local; заявка админу кнопками; сценарий С1 |
| свободный чат | `llm.py::chat` | action=none → общение без истории; сценарий С6 |
| поиск поставщиков (ZAKUP) | `searchers/` (`base.py` — `Supplier`+`SOURCES`, `yandex.py` — основной, `glm_web.py` — фолбэк), `zakup_sheets.py`, `llm.parse_request`/`rank_results` | бриф → кнопки источника → коннекторы → ранжирование → чанки ≤4000; таблица ZAKUP (Запросы/Поставщики/Пользователи); детали коннекторов — `журнал_решений.md` (ZAKUP); сценарий С7 |
| веб-дашборд | `web/dashboard.py`, `web/templates/` | вход по DASHBOARD_PASSWORD (cookie), `/` — запросы, `/request/{№}` — поставщики; `/health`, `/notify`, `/tgwebhook` — вне auth-middleware; сценарий С8 |
| деплой / Render | `артефакты/tbot.json` → `delivery`, `smoke` | runbook (push → deploys API → live → getWebhookInfo), 13 env-переменных, грабли Render API |

## Обязательный контекст агента (§ 3.6)

Перед любой задачей: `AGENTS.md` (ядро) + этот роутинг + `постановка.md` и
`контекст.md` своего узла. Всё остальное — по маршрутам выше, по мере
необходимости; прочитанное фиксировать в `контекст.md` узла.
