## Найденные дефекты (существовали до методологии; код не менялся)

1. **КРИТИЧНО для голоса. `bot.py::on_voice` — NameError: `uid` не
   определён** (строка `dialogs[uid] = {...}` после успешной расшифровки).
   Подтверждено симуляцией: `NameError: name 'uid' is not defined`.
   Следствие: кнопки «Распознал… Продолжить?» не отправляются, голосовой
   ввод не доходит до записи. Фикс — одна строка `uid = m.from_user.id`
   после check_access.
2. **`web/dashboard.py:69` — TypeError на не-ASCII пароле.**
   `hmac.compare_digest` не поддерживает кириллицу: неверный пароль с
   русскими буквами → HTTP 500 вместо формы «неверный пароль» (подтверждено
   живым тестом: 500). Верный пароль работает. Фикс — сравнивать
   `.encode()`-байты.
3. **`bot.py:330` — KeyError: 'question'** при отправке текста вместо кнопки
   в диалоге «какую строку менять?» (в dialog edit_pick нет ключа question).
   Подтверждено симуляцией: `KeyError: 'question'`. Пользователь получает
   тишину. Фикс — `d.get('question', 'уточнение')` или очищать edit_pick при
   тексте.

Мелочи (не блокируют): неиспользуемая `d2` (bot.py:444), неиспользуемый `e`
в except (bot.py:263), close_task(int(...)) без защиты от нечислового ответа
LLM (bot.py:357).
