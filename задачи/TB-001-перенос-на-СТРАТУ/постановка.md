## Что нужно получить

Основной проект переведён на структуру методологии СТРАТА (адаптация в
`D:\ZCode\Project\MOTODA\02_адаптация\`): каждая сущность — отдельный файл —
паспорт артефакта, критерии приёмки, контекстный роутинг, журнал решений,
узлы задач с постановкой и рабочей памятью.

## Зачем это нужно

Знание проекта перестаёт жить в чатах и совмещённых файлах: задачи
продолжаемы новым агентом, проверка идёт по отдельному файлу критериев,
поставка — по runbook из паспорта, решения — в журнале. Решение Александра
от 15.09.2026: репетиция переноса выполнена в клоне TBot2, проверена
независимым агентом-проверяющим; теперь методология накатывается на
основной проект, а TBot2 удаляется во избежание путаницы.

## Границы работы

- Входит: создание процессных файлов, расщепление `docs/FUNCTIONALITY.md`
  и влитие `docs/zakup_history.md`, заглушки-ссылки в старых файлах,
  перевод `AGENTS.md` на ядро (локальный файл, вне git).
- НЕ входит: любые изменения кода бота; деплой; push; правка секретов
  (`config_local.py`, `service_account.json`); удаление старых файлов
  (только заглушки).

## Ожидаемый результат

Набор файлов по целевой структуре адаптации (§ 3
`адаптация_под_проекты_Александра.md`): `контекстный_роутинг.md`,

`задачи/TB-001-перенос-на-СТРАТУ/` + переписанный `AGENTS.md`.

## Ограничения

- Репозиторий публичный — в новых файлах не должно быть секретов.
- `AGENTS.md` остаётся в `.gitignore` (не публикуется) — его перевод не
  коммитится.
- Коммиты частые и мелкие; push и деплой в этой задаче не выполняются.

## Критерии приёмки

1. Все файлы целевой структуры существуют и заполнены.
2. Содержимое `docs/FUNCTIONALITY.md` и `docs/zakup_history.md` полностью
   отражено в `критерии_приёмки.md` / `артефакты/tbot.json` /
   `журнал_решений.md`; старые файлы — заглушки со ссылками.
3. Ничего из знаний старых файлов не потеряно (перенос уже сверён
   независимым проверяющим на репетиции в TBot2 — замечания закрыты).
4. `python -m py_compile` всех модулей проходит — код не тронут.
5. История git сохранена, коммиты переноса добавляются сверху.
6. В новых файлах нет секретов (токенов, ключей, паролей).
